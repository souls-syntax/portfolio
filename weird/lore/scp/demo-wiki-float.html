Example 3 — Multiple images, anywhere you want

First image — right side

You can keep inserting images anywhere in the flow. Just drop a floated image div before the paragraph you want it to appear next to. The text will automatically wrap around it. This is the exact same technique Wikipedia uses for all of its article images.

The key insight is that the image must come BEFORE the text in the HTML source. The browser sees the float, reserves space for it on the specified side, and then flows the remaining inline content around it.

Second image — left side

Now this paragraph wraps around the second image on the left side. You can keep alternating or stacking them. The float property is what makes this work — not flexbox, not grid. Good old CSS floats.

When the text is long enough, it will continue flowing below the image and span the full width again. This is natural float behaviour and exactly what you want for a wiki-style layout.

If you ever need a section to START fresh below all images (no wrapping), just add class="clear" to it. That's the clear:both trick. This gives you full control over where the wrapping stops.

📋 CHEAT SHEET — The Pattern

Rule 1: Parent must be display: block (the default). NOT flex. NOT grid.
Rule 2: Image div gets float: right or float: left.
Rule 3: Image div must come BEFORE the paragraphs in HTML source.
Rule 4: Give the image a fixed width (e.g. 250px, 300px).
Rule 5: Use margin to create spacing between image and text.
Rule 6: To stop wrapping, use clear: both on the next element.

HTML structure:
<div class="wiki-section"> ← block container
  <div class="wiki-img-right"> ← floated image
    <img src="...">
  </div>
  <p>Text wraps around...</p>
  <p>More text...</p>
</div>

CSS:
.wiki-img-right { float: right; width: 250px; margin: 0 0 15px 20px; }
.wiki-img-left { float: left; width: 250px; margin: 0 20px 15px 0; }
.clear { clear: both; }
